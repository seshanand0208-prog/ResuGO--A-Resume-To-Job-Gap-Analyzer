## Required & Optional Environment Variables (`.env`)

1. **`GEMINI_API_KEY`**: Required for server-side resume parsing, gap analysis, builder AI assist, bias-safe name parsing, cover letters, and career copilot.
2. **`ENCRYPTION_KEY`**: 32-character secret used for AES-256-GCM encryption of stored resume text and HMAC signing of `resugo_human_verified` cookies & bot challenges.
3. **`SQL_HOST`, `SQL_DB_NAME`, `SQL_USER`, `SQL_PASSWORD`, `SQL_ADMIN_USER`, `SQL_ADMIN_PASSWORD`**: PostgreSQL connection credentials (injected automatically in AI Studio Cloud SQL, or supplied from Supabase/RDS when self-hosting).
4. **`VITE_RECAPTCHA_V3_SITE_KEY` & `RECAPTCHA_SECRET_KEY`** *(recommended in production)*: Enables live Google reCAPTCHA v3 scoring (and `VITE_RECAPTCHA_V2_SITE_KEY` for checkbox fallback). When omitted in local development, the signed accessible math verification challenge remains active server-side.
5. **`SERPAPI_KEY`** *(optional)*: Live Google Jobs listings via SerpAPI (`engine=google_jobs`); falls back to Gemini Search Grounding when omitted.
6. **`GOOGLE_CSE_API_KEY` & `GOOGLE_CSE_CX`** *(optional)*: Role skill demand & market salary benchmarks via Google Custom Search JSON API.
7. **`RESEND_API_KEY`** *(optional)*: Dispatches real Fit Radar email alerts.

## Deploying to Vercel + Supabase or Cloud Run

1. **PostgreSQL (Supabase or Cloud SQL)**:
   - Provision PostgreSQL and set `SQL_HOST`, `SQL_DB_NAME`, `SQL_USER`, `SQL_PASSWORD`, `SQL_ADMIN_USER`, and `SQL_ADMIN_PASSWORD`.
   - Push the Drizzle schema via `npx drizzle-kit push --config=src/db/drizzle.config.ts`.
2. **Firebase Authentication & Google Workspace OAuth**:
   - Enable Google and Email/Password providers in Firebase Console.
   - Add your production domain to Firebase Authorized Domains and Google Cloud OAuth Authorized JavaScript Origins.
3. **Google reCAPTCHA**:
   - Register your domain in Google reCAPTCHA Admin Console and set `VITE_RECAPTCHA_V3_SITE_KEY`, `VITE_RECAPTCHA_V2_SITE_KEY`, and `RECAPTCHA_SECRET_KEY`.
4. **Hosting**:
   - Build command: `npm run build`
   - Start command: `npm start` (serves Express + built Vite bundle on port `3000`).

## Verification & Test Plan

### 1. Bot & CAPTCHA Verification Failure & Recovery
- **Challenge Generation**: `GET /api/auth/challenge` returns `{ challengeId, question, token }` with a server-HMAC signed token.
- **Honeypot & Wrong Answer Rejection**: Submitting `POST /api/auth/verify-human` with a populated hidden `website` honeypot field, an elapsed form time `< 600ms`, or an incorrect challenge answer returns HTTP `403` with `"Verification failed, try again."` and logs the failed attempt per IP/device.
- **Rate Limiting & Lockout**: Repeated failed verifications (`>= 5` in 10 minutes) trigger a 15-minute temporary lockout returning HTTP `429`.
- **Disposable Email Guard**: Signing up with a known disposable domain (e.g. `mailinator.com`) triggers a clear rejection before session creation.
- **Valid Recovery**: Solving the signed accessible math challenge (or submitting a valid reCAPTCHA v3/v2 token) returns HTTP `200`, sets the `httpOnly` `resugo_human_verified` cookie, and unlocks Google Sign-In, Email/Password login, Reset Password, and Guest Mode.

### 2. Name Analysis Engine Edge Cases (Bias-Safe)
- **South Indian Initials Before**: `"K. Ramesh"` parses cleanly (`initials: ["K"]`, `firstName: "Ramesh"`, `lastName: ""`) with an explicit full-form ATS suggestion (`"K. Ramesh"` / `"Ramesh K"`).
- **South Indian Initials After**: `"Ramesh Kumar S"` parses `firstName: "Ramesh"`, `middleName: "Kumar"`, `initials: ["S"]` and preserves South Indian convention without forcing Western surname rules.
- **Casing & Symbol Normalization**: `"mcDONALD"` normalizes to `"McDonald"`; stray emojis/symbols are stripped cleanly.
- **Soft Validity / Spam Flagging**: `"asdf123"` returns `validityStatus: "needs_review"` with clear soft warning flags (numbers/keyboard mash detected) and allows manual user confirmation rather than hard-blocking unusual real names.
- **Mononyms**: Single-word names (e.g., `"Seshanand"`) parse with `firstName: "Seshanand"` and zero errors.
- **Cross-Check & Privacy**: Uploading a resume whose name differs from the signed-in Google profile surfaces a non-blocking mismatch banner allowing canonical name selection; deleting name data clears `name_profiles` completely.

### 3. Custom Resume Builder & ATS Export Verification
- **ATS Single-Column Strict Mode**: Selecting any ATS template (`ATS Classic`, `ATS Executive`, `ATS Technical`, `Fresher Campus`) locks multi-column layouts and photos (`photoEnabled: false`, `columns: 1`) for clean parser ingestion.
- **Gap-to-Fix Loop**: Clicking `"Fix this"` on a missing skill in `ReportView` navigates to `/builder` with the target skill pre-loaded and enforces the **Honesty Guard** warning before adding unverified keywords.
- **Multi-Format Exports**:
  - **PDF**: Generates clean selectable-text PDF via `jsPDF` (`exportResumeToPdf`).
  - **Word `.docx`**: Generates structured OOXML headings and bullet paragraphs via `docx` (`exportResumeToDocx`).
  - **Plain Text `.txt`**: Strips visual formatting into clean ASCII sections (`exportResumeToTxt`).
  - **Web Portfolio**: Toggling public visibility generates a live read-only page at `/p/:slug`.
